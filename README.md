# INTI // Ancient Energy System

Interactive portfolio concept exploring an ancient Andean energy system hidden beneath stone architecture.

## Concept

INTI imagines three resource channels converging below Machu Picchu: water, subterranean heat and a dense black flow. Solar light is received and concentrated through gold geometry, activating a conversion system whose visual language belongs to an ancient Peruvian world rather than generic modern science fiction.

This project is part of the wider **THE KING LLAMA / INTI** creative universe by **Brian Zuñiga**.

## Portfolio goals

- Combine frontend development with visual storytelling.
- Build a clear interactive system rather than a static landing page.
- Explore responsive cinematic interface design.
- Translate original worldbuilding into a coherent digital experience.
- Keep the experience dependency-free and easy to run.

## Features

- Responsive single-page experience.
- Scroll reveal system using `IntersectionObserver`.
- Interactive three-channel activation mechanic.
- Dynamic core state and solar pulse feedback.
- Pointer-reactive energy mechanism.
- Reduced-motion accessibility support.
- Original art direction based on stone, gold, solar geometry and archival language.

## Tech

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- Intersection Observer API

No build step or external JavaScript dependencies are required.

## Run locally

Clone the repository and open `index.html` in a browser.

```bash
git clone https://github.com/brottoB/OBrianEstudios.git
cd OBrianEstudios
```

For local development, a simple static server is recommended:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Design direction

The project deliberately avoids holograms, neon dashboards and generic futuristic machinery. Its system language is built from:

- carved geometry
- solar alignment
- gold as a reflective/conductive symbol
- subterranean channels
- archival labels and coordinates
- restrained motion
