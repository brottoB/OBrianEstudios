# KAY/FIT — Adaptive Training

KAY/FIT is an original portfolio project by Brian Zuñiga: a product-style fitness interface that turns recovery, energy and performance signals into a clear training state and a recommended daily session.

## Why this project

The goal is to demonstrate frontend direction, interaction design, responsive UI and visual storytelling through a compact product experience rather than a generic fitness landing page.

## Features

- Daily readiness dashboard
- Recovery, energy and performance signals
- Simulated adaptive-day recalculation
- Dynamic training state and load
- Interactive workout completion
- Session activation state
- Weekly progress visualization
- Light and dark visual modes
- Responsive layout
- Reduced-motion support

## Tech

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript
- CSS Grid and Flexbox
- IntersectionObserver

## Run

Open `index.html` in a modern browser. No dependencies or build step are required.
